# Notification Hub

[English](README.md) · 简体中文

你离开对话以后，事情还在继续。回复会写完，频道会来消息，后台任务会结束，也可能在哪里出点错。

Notification Hub 把这些事留在桌面上：

- 发生的时候，在右下角轻轻弹一下
- 错过的时候，在通知中心里还能找到

它只管**送达**和**留存**，不把 Hana 拉回前台，也不替你切回哪个会话。

## 🔔 一条通知从哪里来

**三种来源：对话结束、频道消息、状态变化。**

**对话结束**最常出现：某个 Agent 写完了一段回复。工具调用、被你取消的中途、出错而终止的结束，都不会冒充「回复好了」。

**频道消息**会带上是谁、在哪个频道。

- 同一个频道短时间内普通消息太多，它会收成一条摘要，而不是把桌面打成一阵雨。
- 其中重要的那条不参与合并，立刻单独弹出。

**状态变化**包括定时任务完成、活动状态变化，以及运行中的错误。工具错误、模型不可用、被限流，都归在这一类里。错误与失败会以更重要通知的样子出现。

还有一条安静的规则：在设置里写下几个关键词，命中的通知会升为**重要通知**，并改用重要通知专用的提示音。

## 🖥️ 它怎样出现在你面前

**弹窗出现在桌面右下角，由应用自己绘制。**

不用 Windows 原生横幅，按当前的提示音设置出声。点一下，它收起来，同时把这一条在通知页里标成**「刚点开」**。

有些时候它不该出声，比如：

- 你设了**免打扰**时段
- 你把某个会话、某个频道单独静音
- 你选了**「只记录到列表」**

这几种情况下，通知仍然写进列表，只是不打扰你。

弹窗之间也有自己的秩序：正在退出的那张不再挡住点击；从下往上看，是粒子、正在退出的弹窗、正在显示的弹窗。

## 🗂️ 错过之后：通知中心

**两个入口，打开同一页。**

- Hana 设置里的**「通知中心」**
- 卡片中心的**「通知🌸配置」**

页面上有两处：**通知列表**，和这一页的**设置**。

列表可以按全部、对话、频道、状态、重要筛选，可以刷新，可以清空，也可以把某一条的来源就地静音。

历史最多留下 **200 条**，列表里显示多少条可以自己定。同一会话 60 秒内的连续回复会合成一行，并标出合并了几条——这一项叫**「六十秒合并」**，默认开着。

桌上仍然每条都弹、每条都响，合起来的只是列表里这一行。关掉之后，新的回复各自占一行，已经合并的旧记录不拆开。

会话叫什么，只看宿主会话列表里的标题。有标题时，名字和 session id 一起记下；没有标题时显示**「未命名会话」**，这里不会另起一个名字。

## 🎛️ 你可以调的部分

**声音、外观、节奏，都在这一页里。**

**声音**分了几路：聊天、频道、重要通知、状态/兜底各有一套。可以换成内置的几种声音，可以静音，也可以指向自己的声音文件（wav、mp3、m4a、aac、wma；播不出来会回退到内置声音）。

**外观**是一整套的。选一个组合包，就能一键换掉弹窗风格、登场效果、粒子、轨迹、手感、配色和面板主题。想细调，也可以逐项改：

- 布局、卡片风格、配色
- 大小、偏移、舞动风格、物理手感
- 入场效果、粒子形状与轨迹
- 粒子数量与大小

面板本身还有三档字号，和按来源染色。

**节奏**也在这一页：免打扰时段、静音来源、显示方式、点击后是否高亮。

设置页里还能直接预览各类弹窗——单条、连发、频道摘要、状态、错误、任务完成，试过再定。

## 🚫 这一版的边界

这些是这一版明确不做的事。

- 点弹窗或列表项，**不会切回会话**，也不会唤起、恢复 Hana 主窗口
- 没有左侧栏入口，也没有日终回顾
- 扩展详情页不能把**「通知中心」**和**「通知🌸配置」**分开开关
- 弹窗程序目前只针对 Windows

## 📦 安装

当前版本 **0.3.55**，用于 Windows，需要 **HanaAgent >= 0.978.0**。应用 id 是 `notification-hub`。

把整个应用目录放到：

```text
%USERPROFILE%\.hanako\apps\notification-hub
```

放在 `apps` 下，不要放进 `plugins`。换一台机器时，把整个 `notification-hub` 目录拷到同一位置，再从上面两个入口之一打开。
