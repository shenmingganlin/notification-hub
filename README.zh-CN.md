# Notification Hub

[English](README.md) · 简体中文

## 通知为什么会出现

离开对话以后，事情仍在继续。回复会完成，频道会有新消息，任务会改变状态，重要的事件也可能在此时发生。

Notification Hub 为 HanaAgent 留下一个桌面的消息入口：事情发生时，让你看见；一时错过，也能在通知中心里重新找到。通知的用意是传达与留存，不是把 Hana 拉到前台。

## 已经实现

- **桌面提醒。** 使用自定义桌面弹窗，不再使用 Windows 原生通知横幅；支持对话结束、频道消息，以及任务、错误等状态通知。
- **频道聚合。** 开启聚合后，频道消息密集时合成摘要，消息较少时逐条提醒。
- **重要通知。** 关键词可以将通知升格；重要的对话和频道通知使用重要提示音。
- **声音选择。** 提示音可以选择、静音，也可以使用自定义声音。
- **通知历史。** 可以查看和清空，最多保留 200 条记录。
- **视觉设置。** 视觉组合包、弹窗布局、面板主题，以及入场、粒子和退场效果仍可使用。
- **会话名称。** 会话名只从宿主会话列表读取。宿主没有提供标题时，显示「未命名会话」，不另起名字；宿主会话有标题时，同时记下 session id。
- **六十秒合并。** 同一会话 60 秒内的连续回复，在通知列表里合成一行，并显示合并次数。每一条仍然按通知与声音设置，各自弹窗、各自出声。「六十秒合并」默认开启；关闭后，新回复各自占一行，已经合并的旧记录不拆开。

入口只有两处：Hana 设置里的「通知中心」，以及卡片中心的「通知🌸配置」。

## 这一版没有

以下是这一版的边界，不是后续版本的承诺。

- 点击弹窗或列表不会切回会话，也不会唤起或恢复 Hana 主窗口。
- 没有左侧栏入口。
- 没有日终回顾。
- 宿主的扩展详情页不能按入口分别开关。
- 宿主会话没有标题时，不一定记下 session id。

## 安装

当前版本为 **0.3.55**，适用于 Windows，要求 **HanaAgent >= 0.978.0**。应用 id 为 `notification-hub`。将应用的完整目录放在：

```text
%USERPROFILE%\.hanako\apps\notification-hub
```

请使用上述 `apps` 目录，不要安装到 `plugins` 目录。应用使用 manifest 声明的能力。换机器时，复制整个 `notification-hub` 目录到新机器的同一位置，再从上述两个入口之一打开。
